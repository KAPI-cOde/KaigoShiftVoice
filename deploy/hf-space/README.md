# KaigoShiftVoice の公開版

架空の施設「ひだまりの郷」の11月の勤務表を、一言で直して試せます。施設と職員はすべて架空です。実在の人の名前や、病気などの個人の事情は入れないでください。医学的な判断や助言は行いません。

- 試せるのは 2026年11月13日まで（日本時間）
- 一言は1人1時間に30回まで、200字まで
- Excel の表の貼り付けと声の入力は、公開版では使えません（手元で動かす手順はリポジトリの README にあります）

このページの中の埋め込みの画面では一言を送れないことがあるので、別のタブで開く案内だけを出します。直接のページ（https://<作者の名前>-kaigoshiftvoice.hf.space）で開いてください。

ソースコードと手元で動かす手順は GitHub のリポジトリにあります。

## 公開版の守り

- 試す人ごとに、ひだまりの郷の写しを別に作ります。ほかの人の直しは見えません。写しは最後に使ってから2時間で消えます
- Claude へ送るのは、名簿の名前を「職員01」のような番号に置き換えた一言だけです。名簿に無い名前・電話番号・病気のことらしい言葉を見つけた時は送りませんが、見つけきれないこともあるので、実在の人のことは書かないでください
- 一言を送る前に、出力と送り直しまで含めた最大の費用を見積もって帳簿から引き、決めた量を超えたら送りません。帳簿は Space の永続の置き場（/data）があればそこに残し、無ければ起動ごとに小さな量（10ドル）から始めます。公開期間の通算の上限は、この公開版だけの鍵を置いた Anthropic の Console のワークスペースの上限（100ドル）に任せています
