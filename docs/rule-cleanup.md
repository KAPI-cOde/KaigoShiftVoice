# ルールを積もらせない仕組み

ルールは話すたびに増えます。増えるだけで誰も見直さないと、やがて表を作る人がルール全体を把握できなくなります。AI に任せて作ったプログラムが、誰も読めない技術負債になるのと同じ形です。

16人ほどの施設では、職員ごとの事情を含めると、ルールは200件前後になります。作者の現場では、半年で約200件から約225件に増えていました（中身は使わず、件数だけを数えた）。この規模でも作成者が迷わないように、次の4つを組み合わせます。

## 1. 静かなルールを見つけて、見直しに出す

月の表を作った後に、毎月のルールを1件ずつ外して、白紙から表を作り直します。外しても作り直した表がそのルールどおりだった時、その月は「静か」と数えます。何か月も続けて静かなルールは、毎月の見直し（画面8）に片付けの候補として1件ずつ出します。

- 測っているのは「このルールが無くても、表はこのルールどおりだった」ことだけです。画面では「要らない」とは言いません。来月は効くかもしれないからです
- 何か月続いたら出すかは施設の設定（`review.quiet_months`、既定は3か月）です。1か月だけだと、作り直しのたまたまで静かに見えることがあるので、続いた月数で数えます
- ［今月も使う］と答えたルールは、その後また同じ月数だけ静かが続くまで聞きません
- 当てはまる場面が1つも無いルール（辞めた人のルールなど）は、作り直さずに静かと数えます
- 今月だけの頼み・当番（待機など）・撮影用の前提は数えません
- 片付けるかどうかは作成者が決めます。自動では消しません

作り直しの時間は、架空の施設（16人・164件）で11月の1か月分が191秒でした（8つを並べて解く。作り直し1件の計算の量を表作りの20から5に絞った後）。絞る前は131件で524秒でした。月に1回、表を作った後に裏で流す想定です。

### 重なり（同じことを決めている2件）

1件ずつ外すと、同じことを決めたもう1件が守るので、両方とも静かに見えます。両方を片付けると守りが消えます。そこで、静かな札をまとめて外してもう一度作り直し、破れた札は「重なり」に分けます（quiet.py の _joint）。重なりの2件は「同じことを決めている2件」の札1枚にして、どちらか片方だけを片付けられるようにします（［「A」を片付ける］［「B」を片付ける］［両方使う］）。

- 動かせない決まりの下に、相談できる同じルールがある時は、ゆるい方だけが静かになり、強い方は効いたと数えます
- 測った月の後に、重なる相手のルールが期限切れ・片付けで消える月は、静かの候補に出しません（守っていたのは相手かもしれないため。Astra のレビューの指摘）
- 当てはまる場面が無いルール（表にいない人のルールなど）は迷わず決められるので、見直しで先に出し、文も「当てはまる人と日がありませんでした」にします

## 2. 入口で重複を止める

毎月のルールを言った時、同じ所を決める前からの毎月のルールがあれば「前からのルール『…』があります。置き換えますか、別に足しますか」と聞きます。同じ所とは、同じ種類で、同じ人（またはどちらも全員）で、数える勤務・曜日・並びが重なるものです。

- 置き換えると、前のルールを外して、いま言ったルールだけにします。［ひとつ戻す］で前のルールも戻ります
- 運用の都合の回数どうし（「みんな夜勤は月4回まで」など）は、前から新しい方が言った側だけ代わる作りなので聞きません
- 中身が同じで強さ（必ず・できれば）だけ違う言い直しも聞きます（二重に入って、弱めたつもりの前のルールが残るのを止める）
- 日を決めた頼み（15日は休み など）と当番には当てません

## 3. 一覧をたたむ

ルールが15件を超えたら、右の一覧をたたみます。今月増えたルールだけを1件ずつ出し、全員のルールは件数の1行、人ごとのルールは件数と人数の1行にします。表の名前を押すと、その人のルールだけが開きます。何件あっても、開いた時に読むのは数行です。

## 4. なぜこのマスか

マスを押すと、そのマスの勤務を決めているルール（そのマスを数えていて、ちょうど上限か下限にある）と、ほかの勤務にできない理由（その勤務にすると上限を越える）を、3件ずつ出します。並びの式は係数の向きを見て、本当に縛っている時だけ出します。その日の頼み → その人だけのルール → 話して足したルール → そのほか、の順です。

## 片付けを続けても守りが消えないか（測った）

架空の施設（ひだまりの16人に生成した149件を足した161件。`tools/cleanup_sim.py`）で、11月から7か月、毎月の片付けの候補を先に出したボタンで全部片付け続けました。比べ役は、同じ7か月に1件も片付けない場合です（`--no-archive`）。ソルバーは同じ入力で同じ表を作るので、片付けた月より前は両方まったく同じ数になります。

| | 片付けない | 片付ける（既定の3か月） | 片付ける（1か月に下げた） |
|---|---|---|---|
| 5月のルールの件数 | 161件 | 136件 | 131件（4月） |
| 片付けたルールが後の表で破れた場面 | － | 7か月で1場面（1件） | 6か月で5場面（1件） |
| 動かせない決まりの破れ | 毎月0件 | 毎月0件 | 毎月0件 |
| 残したルールの破れ（3〜5月） | 26・36・47件 | 22・33・39件 | － |

- 目安を1か月に下げると、たまたま静かに見えたルール（青木さん 遅番の2連続を避ける）を片付けてしまい、その後の表で毎月1〜2場面破れました。既定を3か月にしたのはこのためです
- 残したルールの破れは、片付けた方が少し少なくなりました。ルールが減った分だけ破れうる場面も減るので、表の質が上がったとまでは言えません。片付けで質が落ちた様子は見えません
- 初めの3か月は測るだけなので、片付けは4か月目（2月）から始まります。最初に出るのは名簿にいない人のルールで、片付けても表は1マスも変わりませんでした

## まだ足りないこと

- ある月にルールをまとめて足すと、翌月の見直しの「先月増えた」がその件数だけ1件ずつ並びます（架空の施設で119件並んだ）。件数が多い時は人ごとにまとめて答えられる形が要ります
- 表が作れない時に、どのルールがぶつかっているかを示す仕組みはまだありません
- 重なりの札の「ゆるい方を片付けても厳しい方で守られます」は、回数の上限・下限の大小だけで決めています。強さ（必ず・できれば）や、全員向けと1人向けの違いはまだ見ていません（敵対レビューの見送り）
- 静かかどうかは月に1回、表を配った時に裏で測ります。架空の161件の施設で1か月200〜250秒（8つ並べて解く）。デモの施設は撮影のために止めてあります
