## 気をつけること

- 解決3の後半（2:15〜）の画面は、11月末の状態から作ります。`uv run shiftvoice demo --base-date 2026-11-30` で開くと、用意した11月の引き受けの記録を数えて、小島さんの3回が出ます。1幕・2幕の後に同じ画面で続ける時は、休みの電話の一言を言って、待機の小島さんで［了承をもらって直す］を押します。試験では `tests/test_act2.py` の `kojima_rest` が同じ操作を行います。この状態は `uv run shiftvoice state save 名前` で保存し、`state load 名前` で戻せます
- 解決2と解決3の前半の間に、ほかの一言（小島さんの試験・菊池さんの早番など）を言わないでください。言うと、休みを移す先の日が変わり、右のルールに「今月だけ」の一覧が増えて、待機当番の位置が変わります
- 開いた直後の案内の帯の「長くても11時間」は、台本の「8時間半」と食い違うので、画面を撮る前に閉じます
- 台本の数字は、撮る日に `uv run pytest -q` と README の数字で確かめ直します。本物の Claude で通す時は、鍵を入れて `SHIFTVOICE_LIVE=1 uv run pytest -q tests/test_t1_act1.py tests/test_act2.py tests/test_act3.py` を流します
