# デモの台本と試験の対応

3分の動画の場面ごとに、画面で何を見せ、どの試験がその操作を通しているか、README のどの数字を使うかをまとめました。せりふは台本の物で、ここには書き写していません。場面は動画の秒で示します。

本番の動画は台本 v7 です（約175秒。秒は最終版で直します）。運営の「スライドではなく、実際に使っている姿を見たい」に合わせ、文字と図は4枚（全国の数・作者が試した勤務表ソフト・Claude の受け持ち・平均化の前後）だけにし、ほかはアプリの画面の上で語ります。見せる一言は3つ（遅番の次の日に早番はきついから、やめてあげて／みんな、遅番が3日も4日も続くのはやめて／早番も遅番も、可能な範囲で平均化して）です。アプリの場面は、作者の声を AI で複製した声をマイクの代わりに流し、スペースキーを押している間に話す形で、手元の音声認識と本物の Claude で撮りました。1つ目の一言の場面には、作者がスペースキーを押す手元を小さく重ねています。前の版（v4）にあった待機当番・12月・Excel の場面は入れていません。それらは README の手順で試せます。

## 動画に出さない物（README には書いてある）

待機当番と休みの電話、引き受けた人に翌月返す案、Excel の表からの取り込み、希望休、ユニットごとの人数は、動画に入れません。README の「審査員の方へ」と docs/details.md の手順で試せます。

## 気をつけること

- 撮る時は、見本を写した新しいデータの場所で `uv run --extra voice shiftvoice demo --voice --data <写した場所>` と起動し、3つの一言を順に話します（data/hidamari の見本そのものと data/runtime には書き込みません）。案内の帯の「長くても8時間半」は、見本の勤務の時刻（遅番22時15分終わり・早番6時45分始まり）から出ます
- 3つの一言の間に、ほかの一言を言わないでください。言うと、直すマスと回数の幅が変わります
- 動画の数字は、撮った表から数え直し、`tests/test_even_spread.py` の固定の試験と README の数字に合わせます
