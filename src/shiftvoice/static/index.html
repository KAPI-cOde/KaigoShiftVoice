Claude の鍵が入っていないので、一言で直すことはできません（表を見ること、自分の施設の表を貼って来月の表を作ることは、鍵なしでできます）。鍵を入れる時は、起動した窓を閉じて（Ctrl+C）もう一度起動すると聞かれます。鍵の作り方は README の「鍵の入れ方」にあります

表

例「岡田さん、15と16は法事で休み」「遅番の次の日に早番はきついから、やめてあげて」。名簿の名前は番号に伏せてから Claude へ送ります。直した後も［ひとつ戻す］で戻せます。

ルール

勤務の並びや負担の偏りを見えるようにして整えるためのアプリです。医学的な判断や助言は行いません。施設と職員はすべて作り話です。
