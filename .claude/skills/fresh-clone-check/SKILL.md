# まっさらな取得で、README どおりに動かす

手元の作業中のリポジトリは、作った本人の環境（.env・作ったデータ・入れた部品）で動いてしまうので、審査員が止まる所が見えません。新しいフォルダで、README だけを頼りに動かします。.claude/agents/fresh-clone-tester.md の役に頼むとよいです。

## 手順
1. 作業用の新しい空のフォルダで `git clone https://github.com/KAPI-cOde/KaigoShiftVoice.git`
2. README を上から読み、「動かし方」を書いてあるとおりに行う。書いていないことは補わず、補わないと進めなかった所をつまずきとして数える
3. 鍵なしで動かす（`env -u ANTHROPIC_API_KEY uv run shiftvoice demo --no-open`）。鍵が要る所では、README と画面が何と言うかを書く
4. 見えないブラウザ（.claude/skills/screen-check の2）で、README の「自分の施設で始める」と「一言で直してみる」の手順を実際に行い、README のボタンの名前・画面の文と合っているかを確かめる
5. 取得の秒、初めての起動から画面までの秒、表を作る秒を測る
6. サーバーと見えないブラウザを止める

## 報告
- 止まった所・迷った所を重い順に（README の行、何が起きたか、どう書けば止まらないか）
- README と画面の食い違い
- 測った秒と、撮った写真のパス

## これまでに見つかった物（2026-11-05）
- 鍵なしで一言を送ると「読み取りに失敗しました」と［送り直す］になり、README の「文字だけで試す」が鍵なしでは動かなかった。鍵なしの時は鍵が要ることを言う形にし、README の節の名前を直した
