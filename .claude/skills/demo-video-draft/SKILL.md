# デモ動画の仮の通しを作って測る

本番の撮影の前に、今のアプリで流れと秒を確かめるための下書きです。作者の顔と声の所は仮の箱と Mac の読み上げで代えます。せりふと字幕は台本から写します（台本は期間の前の構想を含むので、このリポジトリには入れません）。

## 1. 撮る
- 撮影の状態を写しから戻す。1幕・2幕は11月1日の操作の前（`uv run shiftvoice state load start`、基準の日 2026-11-01）、3幕は11月末（`state load end`、基準の日 2026-11-30）
- 録った返事でサーバーを開き（tools/screen_check.py と同じ作り）、Playwright の録画（`record_video_dir`）で場面ごとに操作する。一言を送った時、表が直った時などの出来事の時刻を書き残し、後で切る所に使う
- 見えないブラウザとサーバーは、撮り終えたら必ず止める

## 2. つなぐ
- ffmpeg で場面ごとに切り、計算の待ちは早送りして字幕「計算待ちを短縮」を出す
- 字幕は画像（PNG）で重ね、1本ずつ出す（2本以上を重ねない）
- 読み上げは作者の話す速さに合わせる（作者の録音から測った1秒の字数。Mac の say の -r で合わせる）

## 3. 測る
- 合計が180秒以内か、場面ごとの秒が台本の枠に入るか
- 声の無い秒（`silencedetect=n=-35dB:d=0.8`）。引用を読ませる所と最後のほかは詰める
- 字幕の字数÷出ている秒が7以下か、字幕が重なっていないか
- 1秒ごとの画面を書き出して、自分で見る

## 4. 採点させて直す
- .claude/agents/demo-judge.md の役に、動画・README・概要を採点させる。見せ方で消せる減点だけを、作者が決めた見せ方に反しない範囲で直す
- 作者に見せるのは1日1回にする
